# Reporting a security concern

Send concerns about this showcase, an accidental disclosure, or the linked
Jogada product privately to **[contato@jogada.com.br](mailto:contato@jogada.com.br?subject=Jogada%20Multiplayer%20-%20Security%20report)**.

Include the affected page or component, a description, and minimal reproduction
steps. Use your own test account and redact personal data and credentials.

Do not publish exploit details, tokens, or customer information in GitHub issues.
Do not run load tests or destructive tests against the live game. Ask the
maintainer about a dedicated evaluation environment first.

This repository ships documentation rather than application binaries. Support
windows for commercial software versions are defined separately in the relevant
agreement. This notice does not promise a response deadline or a bounty.
