No public price list, release date, or automated checkout is announced here.
An enquiry does not create a purchase or grant access.

## Intended package

The package is intended to cover the Java server implementation, built around a
game engine plugin architecture, Flutter client and offline mode, local Docker
tooling, Terraform definitions, and technical documentation. The offer will identify the actual release contents,
versions, prerequisites, and any excluded services before purchase.

Game engines and rules follow a plugin architecture. Each game is implemented as
a plugin, making game implementations easy to add, remove, and manage while
reusing the shared multiplayer runtime.

The live reference product is a Buraco game. A different game's rules, client
experience, branding, provider accounts, and deployment configuration require
adaptation. A particular monorepo layout is not promised by this showcase.

## Request access

Include the following in your email:

- Game type and target platforms.
- Team size and number of developers needing source access.
- Intended deployment and timeline.
- Whether you are building your own title or delivering work for clients.
- Any evaluation, onboarding, or procurement requirements.

Keep confidential details in direct correspondence rather than public issues.

The intended fulfillment process is:

1. Agree the package, release, usage rights, access period, and support scope.
2. Complete the applicable agreement and payment process.
3. Provide the authorized developers' GitHub usernames through direct onboarding.
4. Receive and accept invitations to the private source repository.
5. Follow the installation instructions for the licensed release.

Repository access is a delivery mechanism. The commercial license determines
what use of the delivered implementation is permitted.

## Operation and third-party costs

The operator supplies and pays for AWS resources, domains, payment-provider
accounts, app-store accounts, and any other configured external services. Provider
terms and applicable third-party software licenses remain separate from the
Jogada commercial agreement.
