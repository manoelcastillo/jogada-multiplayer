# Documentation feedback

This repository contains the public-facing documentation for Jogada Multiplayer.
Application development and commercial support take place separately.

## Report a documentation issue

Use the [documentation issue form](https://github.com/manoelcastillo/jogada-multiplayer/issues/new?template=documentation.yml).
Include the page, the unclear or inaccurate statement, and the correction you propose.

Issues may be publicly visible. Do not include credentials, payment details,
customer data, private code, or confidential project plans.

## Suggest a change

For small corrections to prose, links, or diagrams, a pull request is welcome.
Explain the change and the source supporting any technical claim. Keep diagrams
self-contained and accessible, with descriptive text alternatives.

By submitting an original contribution, you grant the maintainer a non-exclusive,
worldwide, perpetual, royalty-free right to use, modify, reproduce, and distribute
that contribution as part of this showcase and its associated documentation.
You retain ownership. Only submit material you have the right to contribute.

Before submitting, check relative links and run `git diff --check`.

- Licensing, source access, and onboarding: [contato@jogada.com.br](mailto:contato@jogada.com.br?subject=Jogada%20Multiplayer%20-%20Commercial%20licensing).
- Security concerns: follow [SECURITY.md](SECURITY.md).
